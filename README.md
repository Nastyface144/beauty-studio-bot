# 🌸 Beauty Studio Bot

Демо Telegram-бота для онлайн-записи в бьюти-студию: маникюр, педикюр, брови и ресницы.
Клиент записывается за минуту на инлайн-кнопках, вносит предоплату через Telegram Payments
(ЮKassa) и получает напоминания. Администратор получает уведомления и управляет расписанием
прямо в Telegram.

**Стек:** Python 3.10+, aiogram 3, SQLite (aiosqlite), APScheduler.

## Возможности

### Для клиента
- `/start` — приветствие с названием студии и меню: «Записаться», «Мои записи»,
  «Услуги и цены», «Наши работы», «Контакты».
- **Запись по шагам:** направление (ногти / брови / ресницы) → услуга →
  дополнительные опции (дизайн, снятие, укрепление) → мастер → дата во встроенном
  календаре на 30 дней (по месяцам, листается стрелками ◀️ ▶️) → время → итог с суммой и длительностью.
- **Умный подбор времени:** длительность считается из услуги и опций. Бот показывает
  только то время, куда процедура помещается целиком и не пересекается с другими записями
  или закрытыми интервалами. Дни без свободного времени отмечены в календаре знаком ✕.
- **Предоплата 30%** через Telegram Payments (тестовый режим ЮKassa). После подтверждения
  слот удерживается 15 минут. Если не оплатить за это время, бронь снимается и время
  освобождается.
- **«Наши работы»:** галерея фото по направлениям, листается кнопками ◀️ ▶️.
- **«Мои записи»:** предстоящие визиты. Отменить запись можно не позднее чем за 12 часов.
- **Напоминания** за 24 часа и за 2 часа. После визита бот просит поставить оценку от 1 до 5.

### Для администратора
- Уведомления о новых бронях, оплатах, отменах, снятых без оплаты бронях и оценках.
- Каждый вечер (по умолчанию в 20:00) — сводка записей на завтра.
- `/admin`:
  - **Сегодня / Завтра / Все записи по датам** — календарь с отметками дней, где есть записи,
    листание по дням, карточка записи; запись можно **отменить** — клиент получит сообщение;
  - **Закрыть день или время** — разовый выходной или закрытый интервал (шаг 30 минут);
  - **Отпуск / закрыть период** — выбрать первый и последний день, бот покажет записи, которые
    попадают в период; закрытые периоды видны списком и открываются обратно одной кнопкой;
  - **Выходные по дням недели** — например, каждый понедельник; в эти дни запись закрыта;
  - **Статистика** — предстоящие записи, визиты и сумма за месяц, предоплаты, отмены, средняя оценка;
  - **Журнал** — последние события (брони, оплаты, отмены, действия админа) и ошибки;
  - **Добавить фото в галерею** (раздел → отправить фото с подписью). Удалить фото можно
    кнопкой 🗑 прямо в галерее.

### Интерфейс
- Бот редактирует одно сообщение, а не присылает новое на каждое нажатие. Если сообщение
  нельзя отредактировать (например, текст нужно сменить на фото), старое удаляется.
- Кнопка «◀️ Назад» есть на каждом шаге.
- Тексты на русском, в нежном стиле, с аккуратными эмодзи.
- Ошибки перехватываются: бот пишет в лог, мягко сообщает пользователю и продолжает работать.
  Кнопки из старых сообщений не ломают сценарий: бот просто открывает меню.

## Запуск

### 1. Подготовка
1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID, например у [@userinfobot](https://t.me/userinfobot).
3. *(Необязательно)* Подключите тестовые платежи: @BotFather → ваш бот → **Bot Settings →
   Payments → ЮKassa → Connect ЮKassa: Test**. Скопируйте выданный токен вида `381764678:TEST:...`.

### Быстрый старт
Нужен установленный [Python 3.10+](https://www.python.org/downloads/). На Windows при установке
отметьте галочку «Add python.exe to PATH».

- **Windows:** дважды кликните `start.bat`.
- **macOS / Linux:** выполните `./start.sh` в терминале.

При первом запуске скрипт спросит токен бота, ваш Telegram ID и (по желанию) платёжный токен,
сохранит их в `.env` и установит зависимости. Потом откройте бота в Telegram и нажмите `/start`.
Бот работает, пока открыто окно со скриптом.

Ниже — то же самое вручную.

### 2. Настройка
```bash
git clone https://github.com/Nastyface144/beauty-studio-bot.git
cd beauty-studio-bot
cp .env.example .env
```
Заполните в `.env` как минимум `BOT_TOKEN` и `ADMIN_ID`. Остальное необязательно.

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен бота |
| `ADMIN_ID` | ID администратора (можно несколько через запятую) |
| `PAYMENT_TOKEN` | платёжный токен ЮKassa. Если пусто, работает **демо-оплата** |
| `TIMEZONE` | часовой пояс студии, по умолчанию `Europe/Moscow` |
| `STUDIO_*` | название, адрес, телефон, Instagram, ссылка на карту |
| `WORK_START` / `WORK_END` | график работы, по умолчанию `09:00` / `20:00` |
| `BOOKING_DAYS` | на сколько дней вперёд открыта запись, по умолчанию `30` |
| `DIGEST_TIME` | время вечерней сводки админу, по умолчанию `20:00` |
| `DB_PATH` | путь к базе SQLite, по умолчанию `data/studio.db` |

### 3. Запуск локально
```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m bot
```

### На VPS (круглосуточно)
```bash
sudo apt update && sudo apt install -y python3-venv unzip   # Ubuntu / Debian
cd beauty-studio-bot
./start.sh                              # ввести токен и ID, проверить бота, затем Ctrl+C
sudo ./deploy/install-service.sh        # автозапуск через systemd
```
Логи — `journalctl -u beauty-bot -f` (или «🧾 Журнал» в `/admin`), перезапуск после правки `.env` —
`sudo systemctl restart beauty-bot`.

**Обновление бота на VPS:** `cd ~/beauty-bot && git pull && sudo bash deploy/install-service.sh`

### Или через Docker
```bash
docker compose up -d --build
```
База хранится в `./data` и переживает перезапуски контейнера.

### Тестовая оплата
С тестовым токеном ЮKassa деньги не списываются. Для оплаты подойдёт тестовая карта,
например `1111 1111 1111 1026`, срок `12/30`, CVC `000`. Актуальный список карт есть
в [документации ЮKassa](https://yookassa.ru/developers/payment-acceptance/testing-and-going-live/testing#test-bank-card). Если `PAYMENT_TOKEN` не задан, вместо счёта появится кнопка
«Оплатить (демо)»: так весь сценарий можно пройти без настройки платежей.

## Как это устроено

- **Защита от двойной записи.** Перед созданием брони свободность слота проверяется ещё раз
  под блокировкой, поэтому два клиента не займут одно время одновременно.
- **Удержание слота.** Неоплаченная бронь (`pending`) занимает время, пока не истёк её
  `expires_at`. Планировщик каждые 30 секунд снимает просроченные брони, удаляет счёт и
  сообщает клиенту. Если клиент нажал «Оплатить» в последние секунды, на время оплаты
  бронь продлевается.
- **Задачи переживают перезапуск.** Напоминания и запросы оценки не ставятся в память.
  Планировщик сверяется с базой, а флаги в записи гарантируют, что каждое сообщение
  отправится один раз.
- **Фото галереи** при первом показе загружаются с диска. Потом бот запоминает `file_id`
  от Telegram и отдаёт фото мгновенно.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты покрывают подбор слотов, работу с базой и сквозные сценарии через настоящий
`Dispatcher` с подменённым Telegram API: запись с оплатой (демо и через счёт), «Назад»,
занятые слоты, отмену, напоминания и оценку, галерею и админ-панель.
